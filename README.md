### 👋 About

I work on the infrastructure and security of an enterprise analytics platform: the Terraform, CI/CD and automation that keep Snowflake accounts, the services around them, and the credentials they depend on consistent and recoverable.

I like replacing manual, error-prone procedures with something repeatable and reviewable, and writing the runbook so the next person can follow it.

### 🧰 What I work on

| | |
|---|---|
| 🏗️ **Infrastructure as code** | Reusable Terraform modules, remote state, imports and provider upgrades; tag-pinned releases with per-account plan/apply pipelines |
| 🛟 **Disaster recovery** | Pipeline-driven Snowflake replication and failback; DR environments and runbooks for Airflow, a semantic-layer service and data-load services |
| 🔐 **Security automation** | Password → key-pair authentication, zero-downtime key rotation, Vault access, IaC scanning in CI, allowlist-based input validation |
| 🚀 **CI/CD** | Shared GitLab templates, manual approval gates, migrating pipelines between GitLab instances |
